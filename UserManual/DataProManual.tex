Welcome to RustDataPro! This software was developed at the RUCARES Severe Behavior Program to make tracking session data easier. When you open the program you should immediately be presented with the session prep page and a sidebar with some additional options.

\begin{figure}[htbp]
	\centering
    \includegraphics[width=1.0\textwidth]{DataProHome.PNG}
    \caption{What you should see immediately after start up.}
    \label{fig:my_image}
\end{figure}

Begin by clicking on the blue Select Client button.

\begin{figure}[htbp]
	\centering
    \includegraphics[width=0.5\textwidth]{SelectClient.PNG}
    \caption{Select Client.}
    \label{fig:my_image}
\end{figure}

You will be prompted to look for a client folder that is stored in the DataProClients folder, which is usually at the root of the C: drive. This can be changed but only as a troubleshooting measure. Inside are folders named for the Client ID of the client inside.

After selecting a client the session prep page should autofill with information stored in the folder. In out example the client 7811224253 has been loaded.
